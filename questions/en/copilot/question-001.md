---
question: "Which user can start using the Copilot Free plan?"
documentation: "https://docs.github.com/en/copilot/how-tos/manage-your-account/get-started-with-a-copilot-plan"
---

- [x] A developer with a personal GitHub account and no other Copilot access
- [ ] A developer assigned a Copilot seat through an organization
> Copilot Free is not available to users with a seat through an organization
- [ ] A developer with a managed user account
> Copilot Free is not available to managed user accounts
- [ ] A developer with an existing Copilot Pro plan
> Copilot Free is not available to users with a Copilot Pro, Pro+ or Max plan
