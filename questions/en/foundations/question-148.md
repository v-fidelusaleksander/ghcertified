question: "What happens when a GitHub repository is changed from private to public?"
documentation: "https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/managing-repository-settings/setting-repository-visibility"
---

- [x] Anyone on the internet can view the repository
> Public repositories are accessible to everyone.

- [ ] Only repository collaborators can view the repository
- [ ] The repository becomes archived automatically
- [ ] GitHub disables issues and pull requests for the repository
