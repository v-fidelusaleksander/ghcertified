---
question: "At minimum, which access level to a repository does a user need to delete GitHub Actions cache entries using the GitHub web interface?"
documentation: "https://docs.github.com/en/actions/how-tos/manage-workflow-runs/manage-caches"
---

- [x] Write
> The documentation states that users with `write` access to a repository can delete cache entries in the GitHub web interface.
- [ ] Read
> The documentation names `write` access as the requirement, which is higher than `read`.
- [ ] Triage
> The documentation names `write` access as the requirement, which is higher than `triage`.
- [ ] Admin
> Admin includes write access, but it is not the minimum level required.
